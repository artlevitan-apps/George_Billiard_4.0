# Геворк Бильярдинский 4.0 — TCL Android TV

Персональная 2D-игра в бильярд для Android TV / Google TV с управлением D-pad (стрелки, OK, Назад).
Основана на версии 3.0; сохранены фото Геворка, оформление, названия игроков, пауза и звуки.

## Три режима

1. **Русский бильярд / свободная пирамида (домашняя версия).** Все 16 шаров можно использовать как бьющие. Ударный шар выбирается перед ударом. После касания другого шара любой забитый шар (включая ударный) приносит очко. Первый с 8 очками побеждает. Правила упрощены по сравнению с официальной свободной пирамидой.
2. **Пул «восьмёрка».** Белый биток, сплошные/полосатые, чёрная восьмёрка, заказ лузы перед финальным ударом, нарушения и свободный биток. Преждевременная восьмёрка возвращается на стол — это домашнее правило.
3. **Тренировка одного удара.** Случайная ситуация, указанные шар и луза. Один удар, без таймера. Промах → тот же расклад; успех → новый сгенерированный расклад. Каждый расклад проверяется автоматической симуляцией физики по исходной позиции до показа игроку. Рекорд удачных заданий сохраняется локально.

В матче можно играть вдвоём на одном пульте или против компьютера; тренировочный режим одиночный.
Игроки: ГЕВОРКИУС и МАРИО.

## Пульт TCL

| Контекст | Кнопка | Действие |
|---|---|---|
| Прицел | ← / → короткое нажатие | 0,12° за нажатие |
| Прицел | ← / → удержание | Быстрое, плавно ускоряющееся вращение кия |
| Пул / тренировка | ↑ / ↓ | Накат / оттяжка |
| Русский бильярд | ↑ / ↓ короткое нажатие | Переключить бьющий шар (выделен жёлтым кольцом) |
| Русский бильярд | ↑ / ↓ удержание от 0,39 сек | Настроить накат / оттяжку без смены шара |
| Прицел | OK удержать | Однократное заполнение силы за ~1,55 сек, до максимума |
| Прицел | OK отпустить | Удар (прицел во время удержания фиксирован) |
| Выбор лузы для восьмёрки | ← / → | Перебрать шесть луз, выбранная показана ярким кольцом |
| Выбор лузы | OK | Подтвердить, выбрать направление удара |
| Свободный биток | Стрелки / OK | Перемещение / подтверждение позиции |
| Всегда в игре | Назад | Быстрая пауза / возобновление |

Векторы: **белый** от бьющего шара до первого объекта или борта; **бирюзовый** от прицельного шара до следующего объекта/борта/лузы либо **оранжевый** после отражения от борта. Показываются только **два сегмента**, построенных на геометрии тех же размеров шаров, бортов и луз. Прогноз показывает направление, а не гарантирует попадание при любой силе удара и кручении.

## Звук

Сохранена первоначальная музыка `club-lounge.mp3`, добавлены три оригинальные инструментальные мелодии:
- `night-yerevan.mp3` — «Ночной Ереван»
- `velvet-blues.mp3` — «Бархатный блюз»
- `soft-jazz.mp3` — «Мягкий джаз»

Все мелодии доступны в «Звук и музыка» и полностью автономны; эффекты отдельно включаются и выключаются.

## Android TV / GitHub Actions

В корне присутствуют `build.gradle`, `settings.gradle`, `gradle.properties` и каталог `app` — всё содержимое требуется загрузить в корень GitHub-репозитория.

Автоматический сценарий лежит в `.github/workflows/build-apk.yml`: сборка запускается при каждом push в `main`, а APK помещается в **Actions → Artifacts → Gevork-Billiardinsky-v4-APK**.

**На macOS каталог `.github` скрыт, потому что начинается с точки.** Если Chrome не загружает его при перетаскивании, выполните альтернативный способ:

1. Загрузите обычные файлы и папку `app` в корень репозитория (без директории, в которой лежал ZIP).
2. На GitHub нажмите **Add file → Create new file**.
3. Укажите полный путь **`.github/workflows/build-apk.yml`**.
4. Откройте видимый текстовый файл **`ГОТОВЫЙ_BUILD_APK_YML.txt`** из этого архива, скопируйте всё содержимое в поле GitHub.
5. Нажмите **Commit changes**. GitHub создаст `.github` сам и автоматически запустит сборку.

Не пытайтесь переименовать `.github` в `github` — GitHub Actions тогда не обнаружит сценарий.

`app-debug.apk` — установочный APK для телевизора. Android Studio не требуется. Если APK предыдущей версии был подписан другим debug-ключом (например, при сборке в другом репозитории), для установки может потребоваться удалить старую версию с ТВ — локальный прогресс при этом может пропасть.

## Проверки и ограничения

Проведены автоматизированные браузерные сценарии Chromium: выбор режимов, смена бьющего шара, короткое и длительное прицеливание, вращение, фиксирование траектории при наборе силы, удар, пауза, заказ лузы, правильная/неправильная восьмёрка, штрафы, тренировка (65 случайных решаемых раскладов), повтор после промаха и переход к следующему заданию после удачного удара. Ошибок JavaScript в проведённых сценариях не обнаружено.

Проверено: `node --check` и структура исходников. Сборка APK в GitHub Actions и взаимодействие конкретной версии с реальным пультом TCL здесь **ещё не проверены**. Игровая физика — оптимизированная 2D-модель с трением, столкновениями и ограниченной моделью вращения, а не профессиональный 3D-симулятор.

Оффлайн, без рекламы, покупок, сервера и телеметрии.
