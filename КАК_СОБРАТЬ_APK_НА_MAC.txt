ГЕВОРК БИЛЬЯРДИНСКИЙ 4.0 — ПРОСТАЯ СБОРКА APK

1. Распакуйте этот ZIP на Mac.
2. В GitHub создайте (или откройте) репозиторий. Старую игру удалять не обязательно: можно создать новый репозиторий.
3. Загрузите в корень репозитория папку app и файлы build.gradle, settings.gradle, gradle.properties.
4. Если .github не загрузилась автоматически, нажмите Add file → Create new file.
5. В имя файла вставьте точно: .github/workflows/build-apk.yml
6. В содержимое вставьте ВЕСЬ текст файла ГОТОВЫЙ_BUILD_APK_YML.txt.
7. Нажмите Commit changes. GitHub Actions запустит сборку автоматически.
8. После зелёной галочки откройте Actions → Artifacts → Gevork-Billiardinsky-v4-APK.
9. Скачайте ZIP-артефакт, распакуйте; внутри app-debug.apk.
10. Установите APK на Android TV TCL. Если новый APK не устанавливается поверх старого (несовпадение подписи), сначала удалите старый APK через настройки телевизора.

ВАЖНО: каталог .github скрыт macOS из-за точки, это нормально. Можно не перетаскивать его вообще — шаги 4–6 заменяют его загрузку.

Проверка: APK в облаке ещё не собирался в данном сеансе. Если сборка красная, посмотрите текст первой ошибки (а не жёлтые предупреждения) и пришлите его для исправления.
